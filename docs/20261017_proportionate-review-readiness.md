# Proportionate review for supervised Climate-FCV handover

## Accepted product boundary

The user explicitly prioritized app-wide readiness over individual report repair:
minor inconsistencies are acceptable when they do not materially change a preparation
decision or clearly misstate the project. Useful qualified inference should survive.
Consequential source review and external version-bound human approval remain required.
No automated detector is certified by these changes.

## Implementation

- Reader review v1.13 identifies issue severity and explains decision impact. Minor
  uncertainty retains prose with a visible notice; consequential issues withhold the
  affected thematic answer, or the opening as a unit. Other reviewed answers survive.
- Exact IDs, unique quotes, reason-code consistency and complete mechanical validity
  remain mandatory. Block, malformed review and structural/evidence failure stay closed.
  Legacy issues without severity are consequential, never silently downgraded.
- Minor-only review avoids correction calls. Consequential review retains the existing
  single bounded correction; rejected edits do not discard unaffected original prose.
  No new model stage or additional call allowance is introduced. Revise stays revise.
- Runtime and exports reuse the same admission helper. The reader review notice is
  visible in browser, standalone HTML and Word and bound to export snapshot hashes.
- Native-reader reports use the independently reviewed opening. They no longer display
  its unreviewed executive precursor alongside it, which could reintroduce the same
  flagged claim. The canonical precursor remains available for audit. Legacy outputs
  and normal FCV retain their existing rendering.
- Removed the obsolete renderer-only 40-180-word gate for native answers; the shared
  validator already enforces nonempty text and a 400-word hard ceiling. This prevents
  valid richer answers from silently reverting to gap-only fallback.
- Conditional recommendation review v2.22 prioritizes errors affecting decisions and
  preserves existing per-core handling. Invented funding, commitments, mandates,
  beneficiary eligibility, phase scope and achieved outcomes remain consequential.
- Runtime admission v2.4; renderer v2.24. Reader compiler remains v1.11. No route,
  rating scale, retrieval, normal-FCV prompt or production deployment change.
