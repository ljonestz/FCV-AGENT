# Climate reviewer calibration and evidence-role repair

## Method and scope

Use saved quality12 failure classes to distinguish genuine source errors from
valid qualified analysis before spending another full assessment. Preserve the
application's native schemas, review stages, retry/correction limits, deadlines,
ranking and export boundaries. Targeted checks use the actual configured quality
reviewer and current prompt/client/schema modules in an isolated temporary process.
They do not constitute a full assessment or production certification.

## Changes

- Reader support projects accepted recommendations to proposed-action fields and
  original links. Narrative, limitation and drafting text cannot independently
  certify a factual premise. Retained fields are copied; upstream actions are intact.
- All verified stages distinguish separate facts from an evidenced relationship,
  credit existing provisions, and trace action premises to project evidence.
- Extraction retains material selection/siting/sequencing criteria as atomic facts.
- Core review checks all recommendation premises and verifies claimed omissions
  against source passages, including provisions missing from extracted facts.
- Reader generation/review use complete fact triples, permit faithful weaker
  paraphrases, qualified consequences and conditional benefits, require direct fact
  citations for factual premises, and identify exact defective propositions.
- Prior action acceptance does not shield an unsupported premise repeated in prose.

No new dependency, provider stage, retry, schema or renderer change was added.
